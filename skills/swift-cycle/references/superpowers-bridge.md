# Superpowers 本地衔接条件

项目已选择 Superpowers 实施且需要衔接编号计划时读取。Swift Cycle 默认不依赖它，不安装或修改插件。

## 唯一计划与任务提取

- **唯一计划**：编号里程碑计划是正式正文。writing-plans 的日期路径可由用户路径约定覆盖，不另存 docs/superpowers/plans 日期副本。保留固定中文二级栏目，把目标、约束、设计、规格和审阅关注点放回相应位置。
- **提取前提**：先读实际安装版本指令及解析器。若 task-brief 按 Task N 提取，在“实施顺序”内用三级技术标题，如“### Task 1: W1 比较规则”，与 W 包对应；W 表格或中文包标题本身不等于可解析任务。技术标记原样保留，内容用项目语言。
- **任务输入**：包含必要文件、接口/依赖、行动、验收与文档同步；执行者同时读唯一计划及确认需求/设计。brief 不一定带全局范围与授权，任务引用全局约束而不复制正文。
- **提取边界**：解析器可能只在下一个 Task 标题停止，最后任务可能带入后续总体验证、风险和状态。核对实际输出，标明全局上下文，不能误归最后任务独占职责。
- **不兼容处理**：工具语义与项目规则冲突时保留正式计划并报告，不静默改规则来适配。

## 执行记录与授权

- brief、测试输出、progress 是忽略的临时状态，不是第二份计划或事实正文。可控新输出放根级 tmp/；目录参数及不可控路径按[临时目录约定](document-profiles.md#项目根临时目录)处理，不迁移仍有固定引用的旧材料。
- 结果变化后同步编号计划与 TODO；不删除仍有作用的 workspace 来重新开始。
- 调用 task-start/task-done 前核对工作目录、HEAD、BASE 及测试命令；检查成功且任务实际完成才记完成。Bash 辅助器显式使用已核对的解释器，不依赖执行位或 Windows WSL shim。
- 辅助脚本通过不代表阶段退出、独立审查、用户接受或整套流程兼容。原流程要求的工作树、审阅、提交和整理，仍按当次授权执行；缺授权步骤明确不执行，不由衔接推导安装、提交、推送、多 Agent 或其他外部权限。

## 验证声明

仅有实际运行证据时声明本地最小衔接通过，说明版本、任务边界与范围。静态阅读不等于执行，模拟 fixture 不证明业务采用；完整执行、跨项目采用、目标宿主和长期恢复未测均保持未验证。

一次性结果留维护仓库兼容说明；安装包不依赖包外文件、机器路径或测试身份。
