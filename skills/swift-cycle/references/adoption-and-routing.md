# 一次采用与后台路由

首次采用、接管、阶段判断或授权边界变化时读取。普通已绑定任务不重复加载；文档与目录细则见[统一规约](document-profiles.md)。

## 两层显式性

- 系统层保持 allow_implicit_invocation=false，防止未采用项目被语义误触发。
- 项目层由用户一次显式采用，在 AGENTS.md 建立持久绑定；后续依仓库指令加载 $swift-cycle。
- 一次性审查或咨询不自动采用。用户明确要求初始化、接管或长期使用时才写绑定；仅采用不推定初始化授权。

## 采用流程

1. **核对现场**：读取仓库指令、用户/设计入口、现有文档、忽略规则和 Git 状态。
2. **保护现场**：保留已有文件、用户改动和有效事实来源；可写任务先按[临时目录约定](document-profiles.md#项目根临时目录)建立或复用 tmp/。只读任务只核对缺口，不创建目录或改 ignore。
3. **定位意图与需求**：在实质实施前确认 BLUEPRINT 与 PRD 的来源。新建持续项目交付非空、受跟踪的 docs/BLUEPRINT.md，默认不建根级 BLUEPRINT；旧项目复用完整等价来源并说明映射，缺失时按确认事实和 UNKNOWN 补齐。PRD 保留确认需求，蓝图构想不自动成为实施承诺。
4. **选择最小职责**：按实际缺口采用文档；持续迭代默认维护 docs/PRD.md 或等价来源。小修改不初始化文档树，不建裁剪账本。
5. **判断初始化授权**：获准创建或正式初始化必须有效交付根级 TODO.md、DEVLOG.md；保留有效文件，只补缺失项。按[初始化预检](document-profiles.md#本地记录与初始化预检)处理内容、Git 策略及冲突。
6. **写项目绑定**：在 AGENTS.md 合并下方合同，说明记录入口及同步边界；只补缺失职责，不重置已有记录或复制等价正文。
7. **核对完成条件**：采用/初始化均读回 tmp/ 及适用忽略状态；初始化另读回双文件的有效内容及跟踪/忽略策略。非 Git 不建 Git；缺失、占位、策略或权限冲突明确未完成，分别报告采用与初始化结果。

一次性审查或咨询不创建 BLUEPRINT。README、DESIGN 和按需建立的 docs 首页只放摘要与链接，保持[唯一正文](document-profiles.md#文档职责与按需选择)。

## AGENTS 持久绑定合同

绑定表达下列语义即可，可合并到既有措辞，不要求逐字复制：

```markdown
## Swift Cycle

- 本项目已采用 `$swift-cycle`。处理项目任务时必须加载该 Skill，由 Agent 在后台判断阶段、选择最小文档档位并维护受影响的权威文档。
- 每包的必要验证、受影响文档同步、局部去重及关联入口轻巡属于已批准任务内步骤；不等项目结束，不要求用户重复选择模式。
- 可写任务先核对根级 tmp/ 及 Git 忽略，可控临时材料集中于此；只读任务不创建或改 ignore，工具不可控的临时路径说明例外，不改全局临时环境或缓存。
- 只有出现新的实质授权、目标或架构实质改变、唯一权威无法安全判断时，才请求用户决定。
```

保留项目已有的安全、验证、语言和文档规则。绑定不授予删除、安装、发布、部署、凭据操作或消费者切换权限。

## 内部阶段识别

阶段用于后台判断，不显示为模式菜单。

| 阶段 | 可观察信号 | 内部动作 | 请求决定的边界 |
| --- | --- | --- | --- |
| 首次采用或接管 | 无绑定、职责缺失或当前正文不清 | 确认意图来源，建立绑定和最小职责映射 | 需覆盖/删除已有资产或新增外部权限 |
| 普通推进 | 目标与授权稳定 | 核对需求影响，调整相关设计与工作包，验证并同步 | 新范围或优先级冲突尚未决定 |
| 重大结构变化 | 正文职责、模块、兼容模型、数据或交付层实质改变 | 留变更前事实，按[复用与重构规则](document-profiles.md#代码组织与能力复用)检查职责、依赖、落点及保留行为 | 新目标或架构尚未确认 |
| 里程碑关闭 | 交付、验证及当前行动达到退出条件 | 收敛文档、本地记录、证据与交付引用 | 缺直接证据或仍有未决授权 |

缺陷修正、候选研究、运行集成和文档退役只是路由信号，不形成新子命令。现有合同字段、小型行为或局部实现变化，未改变职责、兼容模型或授权边界时仍属普通推进。

## 自动继续与暂停

同一任务包内，目标、范围、授权和恢复边界不变，且没有新增外部副作用时继续。正常修正与事实同步不逐包请批。

遇到下列变化才请求决定：

- 需要新的实质授权，或目标、架构、关键边界改变；
- 唯一正文位置有多个合理选择，仓库证据无法消解；
- 需要删除、安装、发布、部署、凭据或消费者切换等尚未授权动作；
- 证据否定当前安排，或无法安全恢复。

正常已授权联网调用按当前请求、工具及数据边界执行，不重复请批。请求只说明精确差异、推荐与待决定动作，不把内部档位或模板选择抛给用户。

## 前台输出

汇报实际结果、验证与未验证层、真实问题和下一项行动；需要用户决定时只指出一个明确阻塞或授权事项。后台路由和命令过程只在解释风险时展开。
