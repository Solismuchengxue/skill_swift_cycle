# 当前行动

本地记录按项目确认策略维护。默认使用前核对存在、未跟踪且被 Git 忽略；不自动改变既有记录边界。

## 当前目标

写最近要得到的结果和当前位置。已有编号计划时链接当前工作包，不复制整份计划。

## 行动

- [ ] 写一个当前可执行、可检查的动作；进行中可用短注释，结果与必要验证、说明同步满足后才勾选。

仅保留当前工作和仍有用的近期完成项，不设固定条数，不把旧完成项整批或汇总搬入 DEVLOG。

## 阻塞

写确实无法继续的原因、影响及解除办法；没有阻塞写“暂无”，普通修正不列为等待授权。

## 下一步

写可以安全接着执行的最近动作；未获授权的发布、安装等不自动进入执行。
