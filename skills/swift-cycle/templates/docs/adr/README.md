## 何时创建 ADR

- 候选经过验证并形成长期重要决定。
- 合同、架构、数据或运行边界发生长期变化。
- 替代方案和后果需要跨会话保留。

短期行动留在 TODO，单次失败留在 DEVLOG；未决候选优先留在需求待确认或相关设计，确需独立维护才用 evaluation。

## ADR 模板

仅在已采用 ADR 约定时使用同目录的 `ADR-NNN.md` 作为内容起点；新项目目标文件按 docs 命名保存为 `0001_decision_title.md` 等小写路径。状态、背景、决定、备选、后果和证据按实际需要填写，本提纲不是所有项目的固定模板。既有路径不因此自动迁移。
