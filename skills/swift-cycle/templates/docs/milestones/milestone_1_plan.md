# 里程碑 1 实施计划：结果名称

仅当本阶段顺序、影响或独立审阅需要详细计划时使用。保存为 docs/milestones/milestone_N_plan.md，编号稳定，一阶段一份现行正式计划；不生成空未来计划。

## 目标与关联

写对应阶段、预期结果，链接选入需求、设计与路线图（已有时）；不是直接逐项拆愿景。

## 范围、保留项与授权

写做什么、保留什么、允许推进到哪里；安装、发布、删除、运行等副作用另核对授权。

## 前置条件与依赖

写必要输入、前置结果与实际缺口；条件足够的部分继续，不把普通实现选择当阻塞。

## 交付物与文件职责

定位实际改动及用途，不为每包建目录、分支、提交、报告或新 Agent。

## 实施顺序

按依赖列工作包，每包含小结果、具体行动、完成判断及必要验证与说明同步。短列表、W 编号或表格按需要选择；独立实验也可成包，不采用“全部代码→全部测试→最后整理”。

已采用 Superpowers 且核对解析器后，可以在此用“### Task 1: W1 结果名称”等技术任务标记；保持本文件唯一正式计划和中文二级栏目，不另建日期版计划。

## 验证与退出条件

覆盖正常、失败与总体协作，阶段完成判断独立于逐包勾选，并说明必要人工确认。检查范围与风险相称，不复制报告正文。

## 风险、恢复与停止条件

写真实风险、处理及需要停止的变化；运行或数据改变时才补恢复安排。复杂依赖才配图，易误用命令才展开。

## 当前状态与下一步

写当前包、实际阻塞、必要结果及最近动作；TODO 只链接当前行动而不复制整份计划。阶段完成后收敛旧过程，保留完成范围、必要结论、固定引用和决定。
